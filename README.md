# 🧭 난 내갈길을 간다 — 국립한밭대학교 캠퍼스 길찾기

한밭대 유성덕명캠퍼스를 걸어 다니는 학생을 위한 모바일 웹앱입니다.
수업 핫키를 누르면 **실제 보행로**를 따라 건물 입구까지 경로를 계산하고, 건물 안에서는 **층별 아이소메트릭 도면**으로 강의실을 찾아갑니다.
인터넷이 끊겨도 앱에 내장된 지도로 그대로 작동합니다.

---

## 📌 주요 기능

1. **시간표 연동 핫키** — 월~금 요일별 수업(시간·과목·건물·호실)을 저장하면, 오늘 수업이 홈 화면에 자동으로 뜨고 누르면 바로 길안내가 시작됩니다.
2. **시간 자동 포맷** — `10시`, `10시.`, `오전 10시`, `오후 2시 30분`, `14시`, `2교시`를 넣으면 `10:00` / `14:30`처럼 자동으로 바뀝니다.
3. **실제 인도 기반 경로** — OpenStreetMap 실측 보행로·계단·내부도로 1,275개 지점, 1,462개 구간을 그래프로 만들어 다익스트라 최단 경로를 계산합니다. 건물은 **입구 좌표**까지 안내합니다.
4. **지각 위험 자동 판단** — `다음 수업 시작 − 지금 − 예상 소요`로 여유를 계산해, 이동 시간이 남은 시간보다 길 때만 빨간 경고를 띄웁니다. 쉬는 시간을 손으로 넣지 않습니다. 예상 소요는 GPS가 켜져 있으면 내 위치에서, 꺼져 있으면 홈에서 고른 출발지 또는 **기본 출발지**(처음 값 **D7 미래동**)에서 계산하고, 카드 오른쪽 큰 숫자에 **예상 소요(예: 9분)**를 보여 주고, 아래 한 줄에 `수업 시작 10:00 · 여유 9시간 2분`과 출발지 기준을 작게 적습니다. 지각 위험이면 빨간 경고 배너가 뜹니다.
5. **일반지도 / 항공뷰 / 오프라인 지도** — OpenStreetMap, Esri 위성영상, 그리고 앱에 내장된 SVG 캠퍼스 지도를 버튼으로 전환합니다. 타일을 못 불러오거나 오프라인이면 자동으로 내장 지도로 넘어갑니다. **오프라인 지도도 `＋`/`−`·드래그로 확대·이동**할 수 있고, 지도 위 건물을 누르면 그 건물 상세가 열립니다.
6. **전체 건물 36곳** — N1~N13, S0~S11, D1~D8, 정문·북문·남문. 각 건물을 누르면 ① 설명 ② 층별 시설이 나오고, 경상학관·인문사회관·창의혁신관은 ③ 층별 아이소메트릭 내부지도까지 나옵니다.
7. **아이소메트릭 내부지도 + 회전 표지판** — **경상학관(S3, 7층까지) · 인문사회관(S4) · 창의혁신관(N11)** 3개 건물에만 제공합니다(나머지 건물은 설명·층별 시설 텍스트로 안내). 도면을 손가락으로 드래그하면 회전하고, 폰 방향 센서를 켜면 폰이 향한 쪽이 위로 오며 복도 표지판이 함께 돕습니다. 센서는 기기마다 한 가지 방향 값만 받아(안드로이드 `deviceorientationabsolute`, 아이폰 `webkitCompassHeading`) 최단각 스무딩으로 부드럽게 돌고, 화면을 가로로 돌려도 위쪽이 걷는 방향이 됩니다. 센서를 끄거나 `↺ 정면 보기`·`처음부터 다시`를 누르면 리스너를 확실히 해제합니다. 길안내 중 목적지가 이 3개 건물이면 지도 아래 `🏢 도착 건물 내부지도 보기` 버튼으로 수업 호실 층의 도면까지 한 번에 이어집니다.
8. **GPS 실시간 안내** — 걷는 동안 현재 위치에서 경로를 다시 계산합니다. GPS가 없으면 출발지 건물 기준으로 계산하고, `걷기 시뮬레이션` 버튼으로 경로를 따라 움직이는 모습을 확인할 수 있습니다.
9. **실행 기록** — 도착 완료 시 예상/실제 소요 시간과 `정시 도착 · 지연 · 경로 변경` 상태를 저장하고, 오늘 요약(횟수·걸은 시간·정시 도착률)과 자주 가는 건물(3회 이상)을 보여 줍니다.
10. **기본 출발지 선택(통학생·기숙사)** — 홈 맨 위 `기본 출발지` 버튼을 누르면 시트가 열려 **한밭대 버스정류장(정문)** 또는 기숙사 **6개 동**(한밭관 **D4 안화동·D5 성실동** / 제1BTL **D2 소나무동·D3 목련화동** / 제2BTL **D7 미래동**(여학생 동)·**D8 인재동**(남학생 동)) 중 사는 곳을 고를 수 있습니다. 고른 곳은 이 기기 `localStorage`(`hanbat_map_default_origin`)에 저장되고, GPS가 꺼져 있을 때 홈의 다음 수업 카드와 지도 탭 경로·거리·예상 소요가 그곳 기준으로 즉시 다시 계산됩니다. `처음부터 다시`를 누르면 D7 미래동으로 돌아갑니다.
11. **홈 화면 추가(PWA)** — 헤더의 `📲 홈 화면 추가` 버튼으로 앱처럼 설치합니다. 홈 화면에 뜨는 앱 이름은 **난 내갈길을 간다**입니다(매니페스트 `name`·`short_name`, iOS `apple-mobile-web-app-title`, 안내 모달 모두 같은 이름). 안내 창은 **번호 카드 1·2·3**으로 Chrome(`⋮ → 홈 화면에 추가`), 삼성 인터넷(`≡ → 현재 페이지 추가 → 홈 화면`), iPhone Safari(`공유 □↑ → 홈 화면에 추가`)를 탭으로 보여 주고, 설치 프롬프트가 준비되면 맨 위 **한 번에 설치하기** 버튼이 나타납니다.

## 💻 실행 방법

`index.html` 파일 하나만 있으면 됩니다. 서버·빌드 도구·로그인·DB를 쓰지 않고, 데이터는 브라우저 `localStorage`(`hanbat_map_` 접두사)에만 저장됩니다.

- 휴대폰: https://oyo003911-cloud.github.io/hanbat-campus-map/ 를 열고 **📲 홈 화면 추가**
- PC: 같은 주소를 열거나 `index.html`을 브라우저로 열기

### 테스트용 버튼
- `◀ 전날로 이동` / `다음 날로 이동 ▶` — 앱 안의 날짜를 하루씩 옮깁니다(주말은 건너뜀).
- `오늘` — 기록·시간표·걸음속도는 그대로 두고 날짜·요일만 실제 오늘로 되돌립니다(주말이면 안내 문구).
- `↻ 처음부터 다시` — 저장된 시간표·기록·기본 출발지를 지우고 오늘 날짜로 초기화합니다(출발지도 GPS로, 기본 출발지는 D7 미래동, 다음 수업 예상 소요도 D7 미래동 기준으로 다시 계산, 한 번 확인).

## 🏛️ 내부지도 — 실제 도면을 옮긴 건축 일러스트 2.5D

건물 내부지도는 **건축 일러스트 2.5D**(`iso-samples.html`의 1번 스타일)입니다.
바닥 슬래브 두께, 보는 쪽 반대편만 남긴 외벽, 호실별 파스텔 바닥·낮은 벽체, 호실 번호와 강의실 이름을 함께 적어 한눈에 읽힙니다.

- **도면 그대로의 평면**: 학교에서 받은 CAD 도면 PDF(`S3` 1·4·7층, `S4` 1·4층)에서 외곽선과 호실 좌표를 뽑아 미터 단위로 옮겼습니다.
  - **S3 경상학관**은 긴 복도동 + 남동쪽 **ㄱ자 날개**(1층 108호 강의실 / 4층 옥외휴게공간) 구조입니다.
  - **S4 인문사회관**은 복도동 + **원형 홀**(1층 아트리움 / 4층 옥상휴게공간) 구조입니다.
  - 도면이 없는 층(S3 2·3·5·6층·B1, S4 2·3층, N11 전체)은 같은 건물 평면 안에 그 층의 공식 호실 목록을 배치한 **참고 도면**입니다(N11은 도면 폴더가 없어 참고 도면뿐).
- **색 구분과 범례**: 🟧 내 강의실(★) · 🛗 E/V(파랑) · 🚪 출입구(초록, 1층) · 🚻 화장실(분홍) · 계단(회색)
- **가는 길**: E/V 문 앞에서 복도로 나와 목표 강의실까지 **붉은 실선**을 긋고, 도면 아래에 "E/V에서 나와 왼쪽/오른쪽" 안내를 함께 적습니다.
- **엘리베이터 문 방향(경상학관 S3)**: S3의 E/V는 **계단 쪽(서쪽, E/V 홀) 면**으로 문 두 짝이 열립니다. 문을 나서면 계단 쪽을 보고 나오므로 **복도(남쪽)는 내 왼쪽**입니다. 도면은 E/V 블록의 서쪽 면에 문 두 짝과 바깥으로 열리는 화살표를 그리고(그 면이 보이는 각도에서만), 붉은 동선은 **서쪽 문 앞 E/V 홀**에서 출발해 왼쪽(복도)으로 꺾어 목표 강의실로 이어집니다. 도면을 열면 이 문이 보이도록 S3는 서쪽 면이 보이는 각도에서 시작합니다. 다른 건물(S4·N11)은 복도 쪽(남쪽) 문 그대로이고, 안내도 문을 나서서 복도를 마주 본 기준입니다.
- **1층 평면도**: 경상학관 1층 점자 종별안내판의 평면도와 같게 맞췄습니다 — 북쪽 줄 `101 · 계단 · E/V · 여 · 남 화장실 · 107 · 계단 · 부출입구`, 남쪽 줄 `102 · 103 · 104 · 현관홀(주출입구) · 105 · 과제도서실 · 106 과제도서실`, 남동쪽 날개 `108`.
- 교수님 성함 같은 개인 인명은 공개 저장소에 올리지 않고, 공식 호실·시설명만 표기합니다.

## 🎨 아이소메트릭 스타일 비교 (`iso-samples.html`)

경상학관(S3) 4층(404호 거시경제의 이해 포함)을 세 가지 느낌으로 그려 비교하는 페이지입니다.
**https://oyo003911-cloud.github.io/hanbat-campus-map/iso-samples.html**

| 샘플 | 방식 | 장점 | 단점 |
|---|---|---|---|
| 1 | 건축 일러스트 2.5D (SVG) | 파스텔 벽면·부드러운 그림자, 호실이 가장 잘 읽힘 | 정지 그림이라 실제 3D 느낌은 약함 |
| 2 | Three.js 실시간 3D (CDN) | 반투명 유리 벽·실시간 그림자·360도 관성 회전 | 라이브러리를 인터넷에서 받아야 해 느린 회선에서 무거움 |
| 3 | 모던 내비 다크 (SVG) | 네이버·카카오 실내지도 같은 네온 다크 톤, 길 안내 중 잘 보임 | 밝은 야외에서 상대적으로 어두움 |

- 세 그림 모두 손가락 좌우 드래그로 회전합니다. `index.html`(본 앱)은 이 페이지를 쓰지 않으므로 앱 동작에는 영향이 없습니다.
- 샘플 2만 Three.js(CDN)를 쓰고, 샘플 1·3은 외부 요청 없는 SVG입니다.
