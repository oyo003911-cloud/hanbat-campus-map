# 🧭 난 내갈길을 간다 — 국립한밭대학교 캠퍼스 길찾기

한밭대 유성덕명캠퍼스를 걸어 다니는 학생을 위한 모바일 웹앱입니다.
수업 핫키를 누르면 **실제 보행로**를 따라 건물 입구까지 경로를 계산하고, 건물 안에서는 **층별 아이소메트릭 도면**으로 강의실을 찾아갑니다.
인터넷이 끊겨도 앱에 내장된 지도로 그대로 작동합니다.

---

## 📌 주요 기능

1. **시간표 연동 핫키** — 월~금 요일별 수업(시간·과목·건물·호실)을 저장하면, 오늘 수업이 홈 화면에 자동으로 뜨고 누르면 바로 길안내가 시작됩니다.
2. **시계 다이얼 시간 선택** — [시간표 관리]의 새 수업 폼은 삼성 시계 앱처럼 **오전·오후 / 시(1~12) / 분(00~59) 3열 휠**로 시간을 고릅니다. 손가락 스와이프·마우스 휠·숫자 탭(누르면 그 줄로 스무스 이동) 모두 되고, 가운데 줄만 크고 진하게 보입니다. **시작·종료를 각각** 고를 수 있고(위의 `시작 시간` / `종료 시간` 칸을 눌러 전환), 시작을 바꾸면 종료가 **자동 +90분**으로 따라오며, 종료를 직접 만지면 `↺ 종료 자동(+90분)`으로 되돌릴 수 있습니다. 안쪽 저장값은 지금까지처럼 24시간제 `HH:MM`입니다(오전 12시=00:00, 오후 12시=12:00, 오후 5시=17:00). 종료가 시작보다 빠르면 빨간 안내가 뜨고 저장되지 않습니다. 예전처럼 `오후 2시 30분` 같은 글자를 넣는 입력은 없어졌습니다.
3. **실제 인도 기반 경로** — OpenStreetMap 실측 보행로·계단·내부도로 1,275개 지점, 1,462개 구간을 그래프로 만들어 다익스트라 최단 경로를 계산합니다. 건물은 **입구 좌표**까지 안내합니다.
4. **지각 위험 자동 판단** — `다음 수업 시작 − 지금 − 예상 소요`로 여유를 계산해, 이동 시간이 남은 시간보다 길 때만 빨간 경고를 띄웁니다. 쉬는 시간을 손으로 넣지 않습니다. 예상 소요는 GPS가 켜져 있으면 내 위치에서, 꺼져 있으면 홈에서 고른 출발지 또는 **기본 출발지**(처음 값 **D7 미래동**)에서 계산하고, 카드 오른쪽 큰 숫자에 **예상 소요(예: 9분)**를 보여 주고, 아래 한 줄에 `수업 시작 10:00 · 여유 9시간 2분`과 출발지 기준을 작게 적습니다. 지각 위험이면 빨간 경고 배너가 뜹니다.
5. **일반지도 / 항공뷰 / 오프라인 지도** — OpenStreetMap, Esri 위성영상, 그리고 앱에 내장된 SVG 캠퍼스 지도를 버튼으로 전환합니다. 타일을 못 불러오거나 오프라인이면 자동으로 내장 지도로 넘어갑니다. **오프라인 지도도 `＋`/`−`·드래그로 확대·이동**할 수 있고, 지도 위 건물을 누르면 그 건물 상세가 열립니다.
6. **전체 건물 36곳** — N1~N13, S0~S11, D1~D8, 정문·북문·남문. 각 건물을 누르면 ① 설명 ② 층별 시설이 나오고, 경상학관·인문사회관·창의혁신관은 ③ 층별 아이소메트릭 내부지도까지 나옵니다.
7. **아이소메트릭 내부지도 + 회전 표지판** — **경상학관(S3, 7층까지) · 인문사회관(S4) · 창의혁신관(N11)** 3개 건물에만 제공합니다(나머지 건물은 설명·층별 시설 텍스트로 안내). 도면을 손가락으로 드래그하면 회전하고, 폰 방향 센서를 켜면 폰이 향한 쪽이 위로 오며 복도 표지판이 함께 돕습니다. 센서는 기기마다 한 가지 방향 값만 받아(안드로이드 `deviceorientationabsolute`, 아이폰 `webkitCompassHeading`) 최단각 스무딩으로 부드럽게 돌고, 화면을 가로로 돌려도 위쪽이 걷는 방향이 됩니다. 센서를 끄거나 `↺ 정면 보기`를 누르면 리스너를 확실히 해제합니다. 길안내 중 목적지가 이 3개 건물이면 지도 아래 `🏢 도착 건물 내부지도 보기` 버튼으로 수업 호실 층의 도면까지 한 번에 이어집니다.
8. **GPS 실시간 안내** — 걷는 동안 현재 위치에서 경로를 다시 계산합니다. GPS가 없으면 출발지 건물 기준으로 계산하고, `걷기 시뮬레이션` 버튼으로 경로를 따라 움직이는 모습을 확인할 수 있습니다.
9. **실행 기록** — 도착 완료 시 예상/실제 소요 시간과 `정시 도착 · 지연 · 경로 변경` 상태를 저장하고, 오늘 요약(횟수·걸은 시간·정시 도착률)과 자주 가는 건물(3회 이상)을 보여 줍니다. 120분을 넘는 비정상 장시간 기록은 통계·목록에서 빼고, 이동이 0회인 날의 정시 도착률은 `- %`로 표시합니다.
10. **기본 출발지 선택(통학생·기숙사)** — 홈 다음 수업 카드의 `출발지 · 변경`을 누르면 시트가 열려 **한밭대 버스정류장(정문)** 또는 기숙사 **6개 동**(한밭관 **D4 안화동·D5 성실동** / 제1BTL **D2 소나무동·D3 목련화동** / 제2BTL **D7 미래동**(여학생 동)·**D8 인재동**(남학생 동)) 중 사는 곳을 고를 수 있습니다. 고른 곳은 이 기기 `localStorage`(`hanbat_map_default_origin`)에 저장되고, GPS가 꺼져 있을 때 홈의 다음 수업 카드와 지도 탭 경로·거리·예상 소요가 그곳 기준으로 즉시 다시 계산됩니다. `초기화 (새 학기 시작)`을 누르면 D7 미래동으로 돌아갑니다.
11. **홈 화면 추가(PWA)** — 설정(⚙) 시트의 `홈 화면에 추가`로 앱처럼 설치합니다. 홈 화면에 뜨는 앱 이름은 **난 내갈길을 간다**입니다(매니페스트 `name`·`short_name`, iOS `apple-mobile-web-app-title`, 안내 모달 모두 같은 이름). 안내 창은 **번호 카드 1·2·3**으로 Chrome(`⋮ → 홈 화면에 추가`), 삼성 인터넷(`≡ → 현재 페이지 추가 → 홈 화면`), iPhone Safari(`공유 □↑ → 홈 화면에 추가`)를 탭으로 보여 주고, 설치 프롬프트가 준비되면 맨 위 **한 번에 설치하기** 버튼이 나타납니다.

## 🎨 화면 구성 (2026-11 리디자인)

흰 카드 + 연회색 바탕(`#F2F4F6`) + 토스 블루(`#1B64DA` 글자 / `#2272EB` 버튼)로 전체 화면을 다시 만들었습니다.
위쪽에는 앱 이름과 설정 버튼, 그 아래 월~금 날짜 스트립, 맨 아래에는 홈 · 지도 · 건물 · 기록 4탭이 고정됩니다.

| 탭 | 무엇이 보이나 |
|---|---|
| **홈** | 다음 수업 카드(과목·건물·호실·예상 소요·출발지 변경)와 큰 `길 안내 시작` 버튼, 오늘 수업 목록(행마다 `예정 · 수업 중 · 끝남`, 종료 시간을 넣은 수업은 시작 아래에 `~18:30`을 작게). 수업이 시작 시각을 지나도 끝나는 시각 전이면 `수업 중`으로 남고, 오늘 수업이 모두 끝났으면 **내일(다음 수업 날) 첫 수업을 큰 글자로** 보여 주고 그날 나머지 수업을 `내일 시간표` 목록으로 붙입니다. |
| **지도** | 캠퍼스 지도(일반지도 · 항공뷰 · 오프라인 세그먼트), GPS · 걷기 시뮬, 출발/도착/보행 거리/남은 시간/예상 소요 표, `도착 완료` · 내부지도 보기 · 강의실 변경. |
| **건물** | 검색창 + 구역 칩(전체 · N동 · S동 · D동 · 출입구), 자주 가는 건물, 전체 건물 36곳. |
| **기록** | 오늘 이동 요약, 내 평균 걸음속도, 최근 이동 기록. |

**일반지도는 학교 안쪽만 또렷하게** 그립니다. 기본 OSM 타일을 회색으로 눌러(색·상점 라벨 최소화) 배경으로 물리고,
그 위에 한밭대 건물 외곽선(연회색 + 흰 테두리)과 흰 인도·보행로, 파란 보행 경로(`#1B64DA`, 흰 테두리)를 얹습니다.
캠퍼스 경계 바깥은 반투명 흰 마스크로 한 번 더 눌러 학교 밖 지도가 눈에 덜 들어오게 했습니다.
건물 이름표는 **캠퍼스의 모든 건물**에 붙고(자리가 좁으면 코드만, 확대하면 이름까지), **이름표를 누르면 그 건물 정보(기본 정보 · 층별 안내 · 길찾기)가 열립니다**. 지도 화면 맨 위에는 **예상 소요시간을 48px 큰 숫자**로 먼저 보여 줍니다.
`오프라인` 지도도 같은 톤(연회색 배경 · 회색 건물 · 흰 인도 · 파란 경로)으로 맞췄습니다.

강아지는 그대로입니다 — 링크로 **처음 접속했을 때 한 번만** 7단계 튜토리얼이 열립니다(기본 출발지 → 시간표 관리 → 지도 → GPS 켜기 → 건물 → 기록 → 설정 순서로 직접 눌러 진행, 대상 버튼에 파란 테두리, 말풍선은 화면 밖으로 잘리지 않게 대상 위/아래에 붙고 `건너뛰기`도 있습니다).
다 본 뒤에는 하단 탭바 위 오른쪽에 앉아 꼬리를 흔립니다. 지도 위 강아지는 서기/걷기 자세로 바뀌고, 누르면 볼이 발그레해지며 손바닥과 하트가 뜹니다(진동·효과음).

## 💻 실행 방법

`index.html` 파일 하나만 있으면 됩니다. 서버·빌드 도구·로그인·DB를 쓰지 않고, 데이터는 브라우저 `localStorage`(`hanbat_map_` 접두사)에만 저장됩니다.

- 휴대폰: https://oyo003911-cloud.github.io/hanbat-campus-map/ 를 열고 설정(⚙) → **홈 화면에 추가**
- PC: 같은 주소를 열거나 `index.html`을 브라우저로 열기

### 상단 설정(⚙)
오른쪽 위 설정 버튼을 누르면 시트가 열립니다.
- **효과음·진동** 스위치 — 버튼을 누를 때 나는 소리와 진동을 켜고 끕니다.
- **홈 화면에 추가** — 설치 안내(Chrome · 삼성 인터넷 · iPhone Safari)를 엽니다.
- **보고 있는 날 / 다른 날 보기** — `◀ 전날` · `오늘` · `다음날 ▶`로 앱 안의 날짜를 옮깁니다. 상단 요일 바 양옆의 `◀` `▶`로도 하루씩 옮길 수 있습니다(하루 전날은 정확히 하루 전, 주말도 그 날짜 그대로).
- **초기화 (새 학기 시작)** — 저장된 시간표·기록·기본 출발지를 지우고 오늘 날짜로 초기화합니다(출발지도 GPS로, 기본 출발지는 D7 미래동, 한 번 확인). 초기화하면 첫 방문 튜토리얼도 다시 열립니다.

## 🏛️ 내부지도 — 실제 도면을 옮긴 건축 일러스트 2.5D

건물 내부지도는 **건축 일러스트 2.5D**(`iso-samples.html`의 1번 스타일)입니다.
바닥 슬래브 두께, 보는 쪽 반대편만 남긴 외벽, 호실별 파스텔 바닥·낮은 벽체, 호실 번호와 강의실 이름을 함께 적어 한눈에 읽힙니다.

- **도면 그대로의 평면**: 학교에서 받은 CAD 도면 PDF(`S3` 1·4·7층, `S4` 1·4층)에서 외곽선과 호실 좌표를 뽑아 미터 단위로 옮겼습니다.
  - **S3 경상학관**은 긴 복도동 + 남동쪽 **ㄱ자 날개**(1층 108호 강의실 / 4층 옥외휴게공간) 구조입니다.
  - **S4 인문사회관**은 복도동 + **원형 홀**(1층 아트리움 / 4층 옥상휴게공간) 구조이고, **1층~5층**까지 있습니다. 1·2·3층은 외국어학과(영어영문·중국어·일본어), 4·5층은 인문교양학부가 씁니다.
  - 도면이 없는 층(S3 2·3·5·6층·B1, S4 2·3·5층, N11 전체)은 같은 건물 평면 안에 그 층의 공식 호실 목록을 배치한 **참고 도면**입니다(N11은 도면 폴더가 없어 참고 도면뿐).
- **색 구분과 범례**: 🟧 내 강의실(★) · 🛗 E/V(파랑) · 🚪 출입구(초록, 1층) · 🚻 화장실(분홍) · 계단(회색)
- **가는 길**: E/V 문 앞에서 복도로 나와 목표 강의실까지 **붉은 실선**을 긋고, 도면 아래에 "E/V에서 나와 왼쪽/오른쪽" 안내를 함께 적습니다.
