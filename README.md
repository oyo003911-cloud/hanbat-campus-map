# 🧭 난 내갈길을 간다 - 국립한밭대학교 캠퍼스 길찾기 웹앱

한밭대학교 신입생 및 재학생이 복잡한 학내 건물 번호와 강의실, 학과사무실, 복지시설을 헤매지 않고 빠르게 찾아갈 수 있도록 돕는 맞춤 길찾기 모바일 웹앱입니다.

---

## 📌 주요 기능
1. **요일별 시간표 연동 및 수업 핫키**: 월·화·수·목·금 요일에 맞춰 '오늘 몇 시에 무슨 수업이 있는지' 실시간으로 바뀌는 원터치 길찾기 핫키.
2. **한밭대 공식 기준 정밀 캠퍼스 맵**: 혜윰광장(중앙광장/분수대)을 축으로 북측 N동(N11 창의혁신관, N1 본부), 남측 S동(S2 학생회관, S3 경상학관, S1 도서관), D7 미래동(기숙사) 등 공식 배치 완벽 반영.
3. **최단 도보 지름길 안내**: 잔디광장 샛길, 솔밭길 등 최단 보행 경로와 예상 소요 시간(분)을 지도 점선 애니메이션으로 시각화.
4. **지각 위험 실시간 재조율**: 쉬는 시간 10분 이하 & 이동 시간 8분 이상 시 '⚠ 지각 위험! 빠른 걸음 권장' 알림 표시.
5. **건물별 층별 안내 & 복지시설**: 창의혁신관, 경상학관 등 각 건물의 층별 호실 및 대학일자리본부, 보건진료소, 학생상담센터 안내.
6. **모바일 최적화**: 360px 모바일 화면에 맞춘 한 손 조작 큰 버튼 및 가로 스크롤 완전 배제.

---

## 💻 실행 방법
별도의 서버 설치 없이 브라우저에서 `index.html`을 바로 열면 실행됩니다.
모든 데이터는 브라우저의 `localStorage`에 안전하게 보관됩니다.
